# Security Policy

## 📌 Supported Versions

Kami hanya memberikan perbaikan bug dan update keamanan untuk versi berikut:

| Version | Status              |
| ------- | ------------------- |
| 1.0.x   | ✅ Supported         |
| < 1.0   | ❌ Tidak didukung    |

Jika kamu menggunakan versi lama, disarankan untuk upgrade ke versi terbaru.

---

## 🔐 Reporting a Vulnerability

Jika kamu menemukan celah keamanan atau kerentanan pada project ini:

1. **Jangan buat issue publik.**  
   Laporkan secara privat agar tidak disalahgunakan pihak lain.

2. **Cara melapor:**  
   - Kirim email ke: `kirakimreal@gmail.com` *(ganti dengan email kamu)*  
   - Atau buat laporan privat lewat [GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories).

3. **Proses respons:**  
   - Kami akan konfirmasi penerimaan laporan dalam **48 jam**.  
   - Update status investigasi dalam **5 hari kerja**.  
   - Patch akan dirilis sesegera mungkin jika kerentanan terbukti valid.  

---

## 🤝 Catatan

- Mohon sertakan detail langkah reproduksi, log error, dan environment (OS, versi, dsb).  
- Reporter yang menemukan bug valid akan kami sebutkan dalam changelog (kecuali diminta anonim).
